# GIS Project Folder Creator

## Project overview

This Python script automatically creates a standard folder structure for a GIS project.

The purpose of the project is to reduce repetitive manual folder creation and improve consistency between GIS projects.

## Folder structure created

The script creates the following folders:

- 01_Input_Data
- 02_ArcGIS_Project
- 03_Scripts
- 04_Working_Data
- 05_Outputs
- 06_Documentation
- 07_Maps
- 08_FieldMaps

## Technologies used

- Python
- os module
- File and folder automation

## How to run the script

1. Download or clone this repository.
2. Open the Python script in PyCharm, Visual Studio Code or another Python editor.
3. Update the base folder path if required.
4. Run the script.
5. Check that the project folders were created.
